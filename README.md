# 📘 PSP Tasks – CS105 (Problem Solving & Programming)

This repository contains the solutions for **Tasks** of the **Problem Solving and Programming (PSP – CS105)** course. The assignment focuses on implementing number-processing algorithms, loops, conditional statements, functions, and mathematical logic using **C++**.

---

## 📂 Assignment Questions

### 🔹 Q1 – Palindrome Number & Odd Digit Analysis

**Objective:**

* Accept a positive integer from the user.
* Determine whether the number is a palindrome.
* Count the total number of odd digits.
* Check whether the count of odd digits is itself a palindrome.
* Allow the user to repeat the program using **Y/y** or exit using **N/n**.
* Provide **three chances** for invalid menu input before terminating the program.

**Concepts Used**

* Loops
* Conditional statements
* Number reversal
* Digit extraction
* Input validation

---

### 🔹 Q2 – Prime Digit Counter

**Objective:**

* Accept a positive integer.
* Scan each digit individually.
* Identify prime digits (**2, 3, 5, 7**).
* Count and display the total number of prime digits.
* Implement a repeat menu with input validation identical to Q1.

**Concepts Used**

* Loops
* Digit manipulation
* Prime number checking
* Input validation

---

### 🔹 Q3 – Pascal's Triangle

**Objective:**

* Accept an integer **n**.
* Print the first **n** rows of Pascal's Triangle.

**Example Output**

```text
1
1 1
1 2 1
1 3 3 1
1 4 6 4 1
1 5 10 10 5 1
```

**Concepts Used**

* Nested loops
* Mathematical calculations
* Pattern printing
* Binomial coefficients
